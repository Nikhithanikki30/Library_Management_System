## 🌟 About the Project

The **Library Management System** is a database project developed using **MySQL and MySQL Workbench**. It helps manage important library activities such as book details, student records, staff information, book issues, returns, reservations, fines, and payments.

The main focus of this project is to design a well-structured relational database and apply SQL concepts to manage and retrieve data efficiently.

## 🛠️ Technologies Used

- **Database:** MySQL
- **Database Tool:** MySQL Workbench
- **Query Language:** SQL

## ✨ Key Features

| Feature | Description |
|---|---|
| 🗂️ 15 Tables | Organizes different library operations |
| 🔍 30 SQL Queries | Retrieves and manages database information |
| 👁️ 5 Views | Displays useful information from tables |
| ⚙️ 5 Stored Procedures | Performs reusable database operations |
| 📊 6 Window Function Examples | Demonstrates analytical SQL functions |
| 🔄 3 Triggers | Automates selected database actions |
| 🔗 Relationships | Uses Primary Keys and Foreign Keys |

## 🚀 How to Run the Project

Follow these steps to run the database project:

1. Install **MySQL Server** and **MySQL Workbench**.
2. Open MySQL Workbench and connect to your local MySQL server.
3. Open the SQL scripts from the `database` folder.
4. Execute the database creation script.
5. Execute the table creation and sample data scripts.
6. Run the remaining scripts to explore queries, views, stored procedures, window functions, and triggers.
7. Use SQL queries to view and manage library information.
