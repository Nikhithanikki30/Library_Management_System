# Library Management System

## 1. Project Overview

The Library Management System is a database project developed using MySQL. It helps manage library operations such as books, authors, publishers, students, staff, memberships, book issues, returns, reservations, fines, and payments.

The main purpose of this project is to organize library information and make data retrieval and management easier using SQL queries.

## 2. Project Objectives

- Maintain book and author information.
- Manage student and staff records.
- Track book availability.
- Record book issue and return details.
- Manage student memberships.
- Maintain reservation information.
- Track fines and payments.
- Manage suppliers and purchase orders.
- Generate useful reports using SQL queries.

## 3. Technologies Used

- Database: MySQL
- Database Tool: MySQL Workbench
- Query Language: SQL

The project provides a structured database for managing library records. It also demonstrates how SQL can be used to retrieve, organize, and analyse information across multiple related tables.
